# 🚘 Carros Antigos

## 📌 Sobre o Projeto

Este projeto consiste em um site sobre carros antigos, desenvolvido para apresentar diferentes modelos de veículos clássicos. O site permite escolher entre automóveis como Porsche 912, Mustang 1969, Lamborghini Miura, Volkswagen Fusca e Chevrolet Camaro 1993, cada um com sua própria página.

O projeto foi desenvolvido para praticar os conhecimentos de desenvolvimento web adquiridos durante os estudos em Desenvolvimento de Sistemas.

## 🚀 Tecnologias Utilizadas

- **HTML5:** criação e estruturação das páginas do site.
- **CSS3:** estilização e organização visual das páginas.
- **Imagens e vídeos:** recursos visuais relacionados aos veículos apresentados.
- **Git e GitHub:** armazenamento e versionamento do projeto.

## ✨ Funcionalidades

- Página inicial com opções de carros antigos.
- Páginas individuais para diferentes modelos de veículos.
- Apresentação visual dos automóveis.
- Organização de imagens e vídeos relacionados aos carros.

## 📂 Estrutura do Projeto

```text
carrosAntigos/
├── CSS/          # Arquivos de estilização
├── imagem/       # Imagens dos veículos
├── vídeo/        # Vídeos utilizados no site
├── .gitattributes
├── camaro.html   # Página do Camaro
├── fusca.html    # Página do Fusca
├── index.html    # Página inicial
├── miura.html    # Página do Miura
├── mustang.html  # Página do Mustang
└── porsche.html  # Página do Porsche
```

## ▶️ Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/LucasMiguel822/carrosAntigos.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd carrosAntigos
   ```

3. Abra o arquivo `index.html` em um navegador para visualizar o site.
